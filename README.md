# BhooShanket 🌐

## AI-Based Early Warning & Landslide Risk Monitoring System

BhooShanket is an AI-powered disaster management system designed to monitor and predict landslide risks across the North Eastern Region (NER) of India.

### 🎯 Problem Statement

**SIH26001 – AI-Based Early Warning and Landslide Risk Monitoring System in NER**

### 💡 Objective

To provide early detection of landslide risks using environmental data, AI-based risk prediction, IoT sensors, and GIS visualization, enabling authorities and communities to take timely preventive action.

### 🚀 Key Features

- 🗺️ Live Landslide Risk Map
- 📡 IoT Sensor Monitoring
- 🤖 AI-Based Risk Prediction
- 🚨 Early Warning Alerts
- 📊 Historical Risk Analysis
- 📄 Disaster & Risk Reports
- ⚡ Risk Event Simulation
- 🏛️ Authority Dashboard

### 🔄 System Workflow

**Data Collection → AI Risk Prediction → GIS Visualization → Early Warning → Preventive Action**

### 🛠️ Technology Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Recharts
- GIS / Map Visualization

### 📍 Target Region

North Eastern Region (NER), India

### ⚠️ Demo Notice

This project is a prototype developed for **Smart India Hackathon** demonstration purposes. Sensor readings, risk scores, predictions, and alerts use simulated/demo data.
